
# Interactive Calculator & Unit Converter

## About the Project
A beginner-friendly Python command-line application
that performs basic arithmetic and converts distance
and temperature units.

## Features
- Addition, subtraction, multiplication and division
- Kilometres to miles and miles to kilometres
- Celsius to Fahrenheit and Fahrenheit to Celsius
- Input validation and error handling
- Repeating menus using while loops
- Separate functions for each task

## Technologies Used
- Python 3
- VS Code
- Command-line interface (CLI)

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   python calculator.py

## Concepts Learned
Functions, conditional statements, loops, user input,
type conversion, exception handling and debugging.
